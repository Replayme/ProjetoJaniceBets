# Projeto Janice Bets

Site informativo sobre os danos das casas de apostas (bets) na sociedade brasileira e no cérebro.

Site estático (HTML, CSS e JavaScript puro), sem build nem dependências.

## Rodar localmente

Abra `index.html` no navegador ou sirva a pasta:

```sh
python3 -m http.server 8000
```

e acesse http://localhost:8000.

## Publicar

Qualquer hospedagem estática serve (GitHub Pages, Vercel, Netlify). Aponte para a raiz do repositório.

## Conteúdo e fontes

Os números do site foram colhidos de reportagens e artigos científicos listados na seção **Fontes** da página. Antes de divulgar, confira os valores nos relatórios originais (Banco Central, IEPS, Ministério da Saúde) e atualize `index.html` se houver dados mais recentes.
